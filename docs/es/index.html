Proyectos

Trading algorítmico y análisis cuantitativo Proyecto personalEn curso

Herramientas en Python para investigar y validar estrategias de trading algorítmico sobre futuros de criptomonedas, combinando desarrollo de software, IA y análisis cuantitativo de mercados.

  • Recogida automatizada y procesamiento de datos históricos OHLCV con NumPy y técnicas estadísticas.
  • Simulaciones y backtesting, con análisis de robustez, riesgo y sesgos estadísticos, y comparación de estrategias con grupos de control.
  • Investigación reproducible: pruebas automatizadas, verificación de la integridad de los datos con SHA-256 y procedimientos de reproducibilidad científica.
  • Uso de agentes autónomos de IA para acelerar el desarrollo y las pruebas.

Integración de datos ERP → Salesforce Proyecto personalEn curso

Proyecto de integración de sistemas de principio a fin, hecho para practicar cómo circulan los datos entre un sistema de gestión y un CRM.

  • ERP simulado creado desde cero: una API REST (FastAPI + SQLite) que sirve datos sintéticos con errores introducidos a propósito.
  • Proceso en Python que extrae los datos por API, los limpia, elimina los duplicados y los sincroniza de forma incremental con Salesforce.
  • Dentro de Salesforce, automatizaciones con Apex y Flows reaccionan a los cambios que llegan.
  • Batería de pruebas automatizadas con pytest.
